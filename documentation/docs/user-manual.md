# User's Manual
## Set-Up and Usage
The bot is activated via a slash command: /search where it then prompts the user for a query. On the dev side of things, the discord bot simply needs to have guild install active on the Discord Dev Portal where bots are made, and to have the following registered:
- Scopes: bot, applications.commands
- Permissions: embbed links, messages
